## 2026-02-19 - [Feedback Aggregation]
**Learning:** Rapid-fire UI notifications (like multiple Snackbars) can collide and overwrite each other, causing the user to miss important feedback.
**Action:** Aggregate batch operation results into a single comprehensive notification message to ensure clarity and visibility.

## 2026-02-19 - [Visual Cues for Export]
**Learning:** Using specific icons like `DownloadIcon` for export actions helps users instantly distinguish between data-saving actions (Upload) and data-retrieval actions (Export).
**Action:** Always include relevant icons for primary action buttons to improve intuitive navigation.
